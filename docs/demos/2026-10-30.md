# GeneralRouter v0.1.13: recorded workflow

[Watch the 43-second demonstration](generalrouter-demo.mp4) · [Project overview](../PROJECT-OVERVIEW.md) · [Core algorithm](../CORE-ALGORITHM.md)

On October 30, 2026, a single coding task passed through GeneralRouter's model recommendation and the main agent's existing Antigravity worker tool. The worker delivered a small CSV score-summary page. The user then clicked **Load example** and **Calculate** in the browser and confirmed **2 valid rows, 2 invalid rows and average score 15**.

The recommendation, tool invocation and artifact are separate observations. The record establishes that an Antigravity worker ran; it does not establish that the underlying execution model was the recommended Argon/high configuration.

## What this establishes

This is a limited demonstration of the current separation of responsibilities: Router recommends; the main agent chooses an installed execution tool and handles the result. It is distinct from the [v0.1.7 translation-extension comparison](../experiments/translation-ab-v2/README.md).

- One manually checked example does not establish comprehensive correctness or browser coverage. No automated acceptance suite was run for this demonstration.
- The same-model repair branch was not exercised.
- Actual worker model and effort remain unconfirmed, so model-recommendation fidelity was not established.
- External worker token events were not available in the Router report. Zero observed worker usage records means unknown usage, not zero consumption. Complete workflow cost is unknown.
- This was not a paired experiment and supports no new claim of time, cost, quota or quality improvement.
- Twelve scored configurations are not proof of twelve working execution routes.

The capability scores draw on retained Artificial Analysis data; task emphasis is a planner estimate using project-defined semantic examples. See the [method](../CORE-ALGORITHM.md) and [source attribution](../../THIRD_PARTY_NOTICES.md).
